How to Create Strong Passwords

A strong password makes it harder for someone to access your account. The best approach is to use a long, unique password for every important service and add another layer of security.

What makes a password strong?

Length and uniqueness matter. A long passphrase made from several unrelated words can be easier to remember and harder to guess than a short, predictable password. Avoid names, birthdays, phone numbers, keyboard patterns and common phrases.

Five practical password habits

  1. Use a different password for every account. If one service is breached, attackers cannot automatically reuse that password elsewhere.
  2. Make important passwords long. Use a memorable passphrase or a randomly generated password.
  3. Use a reputable password manager. It can generate and store unique passwords so you do not have to remember all of them.
  4. Turn on multi-factor authentication (MFA). An authenticator app, passkey or security key can provide extra protection beyond a password.
  5. Never share verification codes. Treat one-time codes and recovery codes like passwords.

What should you do if a password is exposed?

Change it immediately on the real website or app, and change it anywhere else you reused it. Sign out other sessions if the service offers that option, check account recovery details and enable MFA. If you suspect someone has accessed your email account, secure that account first because it may be used to reset other passwords.

Are password changes needed every month?

Changing a password on a fixed schedule is not a substitute for making it strong and unique. Change it promptly if you think it has been exposed, if you shared it accidentally or if the service tells you there has been a security incident.

Safety tip: A legitimate support agent should not ask you to tell them your password or one-time sign-in code.
