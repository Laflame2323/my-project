# TechLearn Guide

A responsive beginner-friendly educational website about artificial intelligence, programming, cybersecurity and digital skills.

## Files
- `index.html`: Homepage
- `style.css`: Responsive visual design
- `script.js`: Mobile navigation and footer year
- `about.html`, `contact.html`, `privacy.html`: Supporting pages
- `articles/`: Original introductory learning articles

## Preview
This is a static HTML/CSS/JavaScript site. Open `index.html` in a browser or publish it with a static hosting provider.

## Before public launch
1. Replace the placeholder site URL in `robots.txt` and `sitemap.xml` with the actual published URL.
2. Add a real contact email after creating one.
3. Review every article for accuracy and continue publishing original, useful content.
4. Update the privacy policy if analytics, advertising, forms or other third-party services are added.

Google AdSense approval and earnings are not guaranteed. A functioning website, useful original content, policy compliance and sufficient site quality are important.
